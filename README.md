✦ What is FocusLock?

FocusLock puts a simple barrier between you and distracting apps.

Choose → Limit → Focus.

✨ Highlights

- ⏱️ Custom app limits
- 🔒 Automatic focus protection
- 🎯 Intentional unlock challenges
- 📊 Usage monitoring
- 💾 Import & export
- 🎨 Modern Android UI
